About MX

MX sends fake GPS location on WhatsApp instead of your real location.

FIRST TIME SETUP (Required)
1. Allow Location permission
2. Allow Notification (optional)
3. Open Developer Options
4. Enable "Mock location app"
5. Select "MX" from the list
Without this, MX will NOT work.
HOW TO USE
1. Tap "Tap to Select Location"
2. Enter place name or coordinates
3. Tap "Confirm"
4. Tap "START" to begin
5. Open WhatsApp → Share Live Location
6. Tap "STOP" when done
• MX runs as foreground service
• Stop MX from app or notification bar
• Android only — not supported on iOS
