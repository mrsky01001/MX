ABOUT MX

MX sends fake GPS location on WhatsApp instead of your real location.

First time setup: Allow Location permission → Open Developer Options → Enable Mock Location → Select MX

How to use: Select location → Tap START → Open WhatsApp → Share Live Location → Tap STOP when done

Android only — not supported on iOS.
